# My-devin Frontend

React + TypeScript + Viteで構築されたWebインターフェース

## セットアップ

```bash
cd frontend
npm install
```

## 開発サーバー起動

```bash
npm run dev
```

ブラウザで http://localhost:3000 を開く

## ビルド

```bash
npm run build
```

## テスト

```bash
npm test
npm run test:coverage
```

## リント・フォーマット

```bash
npm run lint
npm run format
```
